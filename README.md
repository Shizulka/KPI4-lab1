## Запуск тестів

```
Відкрийте вкладку Maven у правій частині екрана IDE.
Перейдіть до папки проєкту -> Lifecycle.
Двічі клікніть на clean, а потім на test.
```

## Запуск алгоритму з файлами

Формат вхідного файлу:

1. кількість поколінь;
2. ширина та висота поля;
3. по одному рядку поля на кожен рядок, де `.` — мертва клітина, `x` — жива.

Приклад `game.txt`:

```text
3
8 5
........
..x.....
..x.....
..x.....
........
```

Результат буде записано в `saves\game.txt` (лише поле, рядки з `.` та `x`). Поле замкнене: клітини на протилежних краях вважаються сусідами.

## Графічний інтерфейс

Можна малювати клітини мишкою, запускати/зупиняти симуляцію та очищувати поле.

- **Зберегти** — за замовчуванням зберігає в `saves/game.txt`.
- **Завантажити** — відкриває файл `saves/game.txt` читає поле. Підтримуються обидва формати: файл із заголовком (`покоління`, `ширина висота`, рядки) та просто поле без заголовка, тож збережений файл можна завантажити назад. Розмір вікна підлаштовується під поле.
